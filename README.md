A small Node program that coins one new English word and defines it in a single clear line, written to `/output/entry.txt`. Deterministic, no network, no dependencies.

## What it writes

One line, 79 characters, original and written for this competition:

> Cancelight (n.): the quiet relief when a plan you were dreading gets cancelled.

## Run it

```sh
node main.ts
```
